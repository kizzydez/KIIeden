Every image shipped with the app, and who owns it. Update this file whenever you add one
(`npm run check:compliance` checks that each image is listed).

|---|---|---|
| logo.jpg | KiiEden logo (full lockup) | Supplied by the KiiEden project owner, who confirms they own or licence it. CONFIRM before launch. |
| logo-mark.png | Square crop of the K mark from logo.jpg (nav, footer, favicon) | Derived from logo.jpg; same rights. |
| logo-k.png | Transparent-background version of the K mark for the home page hero | Derived from logo.jpg; same rights. |
| placeholder.png | Default "unrevealed" placeholder image | Generated for this project (plain geometric shapes on a gradient); no third-party material. |
| icon-192.png, icon-512.png | PWA manifest icons | Derived from logo-mark.png; same rights (confirm the logo before launch). |
| ../app/icon.png | Favicon | Derived from logo.jpg. |

User-uploaded NFT and asset images are not shipped with the app. They are supplied by creators, who confirm
they hold the rights before every launch (see the consent checkboxes and the Terms).
